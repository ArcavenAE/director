One Token, Four Jobs

A design party · 2026-09-18

A ticket asked whether to split the cluster name into two fields or build a bigger identity machine. Five researchers read the code first, and came back saying the name already does everything, and quietly.

The verdict. Keep the single typeable token. It is the JetStream domain, the subject partition, the leaf seed's name, and the credential binding, all at once, and its narrow charset is on purpose because a raw hostname is not a safe NATS token. No bus.domain override, no wider primitive. The label is operator-chosen, lowercase by convention, unique per tier. The seed has no path on the daemon by design; the one on-disk copy is a transient operator-side stage.

The token, and the four surfaces it serves

Split the token and any two of these four can disagree. Keep it, and they cannot.

Ident

Addressing architecture

The token is already the identity primitive. One value, four surfaces, no second source of truth. That is not an accident to refactor; it is the property worth defending.

Tobi

NATS naming and charset

A subject cannot hold a dot, a domain folds into $JS.<domain>.API, and subjects are case-sensitive while hostnames are not. The narrow charset is the safe intersection, not an arbitrary limit.

Rem

Render and Terraform

The Terraform clusters map key is the label, and a map cannot hold two identical keys. Per-tier uniqueness is enforced structurally, for free. The only add is a charset check on the key.

Wend

Operator experience

The human names it once, legibly. Derive it from the hostname and two "MacBook Pro" machines collide. Two clusters on one host? Distinct labels. Two hosts, one name? The operator labels them; the platform will not guess.

Skarp

The keep-it-simple skeptic

My whole case was one sentence: the token exists, it is validated, it is already the domain and the subject; the work is a convention and two doc modes, not a code change. The room did not make it grow, so I had nothing left to object to.

The one real argument

Tobi wanted lowercase enforced in code, to close the Kinu versus kinu trap. Wend refused: enforcing it means silently rewriting the operator's input, which is exactly the surprise the codebase's reject-not-rewrite ruling exists to prevent.

They settled on the posture already in the code: reject an uppercase label with a message, never downcase it behind the operator's back. Lowercase is the convention; the guard rejects, it does not launder.
